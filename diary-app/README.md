# 사적인 문장

한국어 개인 일기장 웹앱. 백엔드와 SQLite 데이터베이스는 이 컴퓨터에서 실행됩니다. 외부 라이브러리, 계정, 인터넷 연결이 필요하지 않습니다.

## 실행

Node.js 24 이상이 필요합니다. 현재 컴퓨터에는 설치되어 있습니다.

`일기장 실행.cmd`를 더블클릭하면 서버와 기본 브라우저가 열립니다. 서버 창을 닫거나 Ctrl+C를 누르면 종료됩니다.

터미널에서는 이 폴더에서 `npm start` 또는 `node server.mjs`를 실행하세요.

접속 주소: http://127.0.0.1:4317

## 기능

- 일기 작성, 수정, 삭제. 하루에 여러 편 작성 가능
- 날짜와 5단계 기분, 아껴둔 문장(즐겨찾기)
- 제목/본문 검색, 날짜/기분/즐겨찾기 필터, 최신순/오래된순
- 달력의 기록 표시, 전체·이번 달 기록 수, 연속 기록 일수
- 브라우저의 작성 중 초안 복구, 미저장 이동 경고
- JSON 백업 다운로드, Ctrl+S 저장 (Mac은 Command+S)
- 여러 창의 동시 수정 충돌 감지
- 휴대폰 크기에서도 사용 가능한 반응형 화면

## 학생 기록

왼쪽 **학생 기록** 메뉴 또는 http://127.0.0.1:4317/students 에서 사용할 수 있습니다.

- 학생 이름, 학년·반, 번호, 날짜, 관찰/상담/학습/생활 분류, 제목, 내용, 후속 계획
- 학생별·분류별 필터 및 이름/반/번호/제목/본문/후속 계획 검색
- 작성·수정·삭제, 브라우저 초안 복구, 미저장 경고, 동시 수정 충돌 감지
- 동일한 이름은 학년·반·번호 조합으로 구분합니다. 같은 학생의 기록에는 같은 정보를 입력하세요.
- 학생 기록 내보내기는 전체 학생 기록을 JSON으로 다운로드합니다.
- 일기장 화면의 기록 내보내기에는 일기와 학생 기록이 모두 포함됩니다.

학생 기록은 기존 `data/diary.sqlite`의 별도 `student_records` 테이블에 저장됩니다. 기존 일기 데이터는 그대로 유지됩니다. 데이터 폴더 전체를 백업하면 학생 기록도 함께 백업됩니다.

### 명렬표로 학생별 보기

제공된 1학년 명렬표의 1~9반 252명을 로컬 `roster_students` 테이블에 등록했습니다. ‘반별 보기’에서 반을 고른 후 ‘학생별 보기’에서 이름을 선택하세요. 기록이 없는 학생도 표시되며 이름 옆에 기록 수가 나옵니다. 선택한 학생의 최신 기록 또는 새 작성란이 열립니다. 새 기록 작성 시 이름·반·번호는 명렬표에서 자동 입력됩니다. 작성란의 ‘명렬표에서 학생 선택’에서도 바로 선택할 수 있습니다.

명렬표 외 학생은 ‘직접 입력’을 선택해 기록할 수 있습니다. 학생 기록 및 일기장 JSON 내보내기에 명렬표도 포함되며, 원본 Excel은 수정하지 않습니다. 명단은 정적 웹 파일에 포함되지 않고 로컬 DB에만 저장됩니다.

유지보수용 재등록: `scripts/extract_roster.py 원본.xlsx data/roster-import.json`으로 추출한 다음 `node scripts/import_roster.mjs data/roster-import.json`을 실행합니다. 같은 학년·반·번호·이름은 중복 등록되지 않습니다. 기존 이름과 다른 명단은 덮어쓰지 않고 오류를 알립니다. 새 학년도 구분 기능은 포함되어 있지 않습니다.

## 데이터와 백업

실제 저장 위치는 `data/diary.sqlite`입니다. 저장 버튼을 눌러야 SQLite에 기록됩니다. 초안은 현재 브라우저의 로컬 저장소에만 보관됩니다.

앱을 다시 실행해도 저장된 일기는 유지됩니다. 데이터베이스는 처음 실행할 때 자동으로 생성됩니다. 예제 일기는 넣지 않습니다.

전체 백업·복원은 **서버를 종료한 후** `data` 폴더 전체를 복사·교체하세요. 서버 실행 중에는 SQLite 보조 파일이 있을 수 있으므로 DB 파일만 복사하지 마세요. '기록 내보내기'는 저장된 기록을 읽을 수 있는 JSON으로 다운로드합니다. JSON 가져오기 기능은 포함되어 있지 않습니다.

서버는 `127.0.0.1`에만 바인딩되어 다른 컴퓨터에 공개되지 않습니다. 로그인과 저장 파일 암호화는 없으므로 이 컴퓨터의 파일에 접근할 수 있는 사람은 일기도 읽을 수 있습니다.

포트 변경: PowerShell에서 `$env:PORT=4318`을 설정한 후 `node server.mjs`. 실행 파일의 기본 포트는 4317입니다.

## 검사

`npm test` 또는 `node --test`: 실제 임시 SQLite 파일과 HTTP 서버를 이용해 CRUD, 영속성, 입력 검증, 충돌, 백업, 접근 제한을 확인합니다. 사용자 데이터는 건드리지 않습니다.

구성: `server.mjs`(HTTP), `store.mjs`(SQLite), `public/`(화면), `test/`(테스트).
